# 제어·통신 주기 기준

[README](../README.md) · [모터 제어 명세](motor_control_spec.md) · [IMU 보정](imu_calibration.md)

모바일 로봇의 온보드 연산 장치(Jetson Orin Nano Super)와 모터 제어 MCU(Arduino Mega 2560) 사이의 제어·통신 주기 설계 기준을 정의합니다.

## 계층별 제어 및 통신 주기

| 계층 · 기능 | 동작 주기 / 속도 | 역할 및 설계 기준 |
| --- | --- | --- |
| 엔코더 샘플링 (Mega) | **20 kHz** | A/B 상 전이 감시 및 불효 전이(글리치) 카운트 |
| 속도 PID · 위치 유지 루프 (Mega) | **1000 Hz (1 ms)** | 결정론적 속도 오차 적분·미분 및 정지 위치 복원 연산 |
| 모터 드라이버 출력 갱신 (I²C) | **400 kHz 버스** (평균 약 580 Hz 갱신) | 제어 루프와 분리된 비동기 출력 전달 (오류 시 100 kHz 폴백) |
| 호스트 $\rightarrow$ Mega 목표 속도 송신 | **50 Hz (20 ms)** | 연속 속도 명령 갱신 (유효기간 300 ms 이내 유지) |
| Mega $\rightarrow$ 호스트 상태 텔레메트리 | **20 Hz (50 ms)** | 엔코더 누적 카운트, 측정 속도, 출력 PWM, 오류 플래그 수신 |
| MCU 명령 유효기간 (Watchdog) | **300 ms** | 상위 제어기 중단 또는 시리얼 단절 시 자동 출력 차단 |

## 역할 분담 원칙

* **Jetson (호스트)**: 센서 데이터 수집, 오도메트리 적산, 상위 경로 추종 제어 및 차체 속도($v, \omega$) $\rightarrow$ 좌우 바퀴 목표 속도 변환을 담당합니다.
* **Arduino Mega (MCU)**: 실시간성이 요구되는 20 kHz 엔코더 디코딩, 1 kHz 폐루프 속도·위치 제어, I²C 드라이버 구동 및 하드웨어 안전 감시를 전담합니다.
* **명령 수명 관리**: 상위 제어 어댑터는 시리얼 송수신을 제어 콜백과 분리하되, 원본 명령의 생성 시각을 보존해야 합니다. 상위 명령이 끊겼을 때 이전 목표를 재전송해 300 ms 유효기간을 인위적으로 연장하지 않습니다.

## UART 링크 프로파일링

모터를 구동하지 않는 상태에서 호스트-MCU 간 프레임 왕복 지연과 UART 대역폭 점유율을 점검할 때는 [`tools/profile_motor_link.py`](../tools/profile_motor_link.py)를 사용합니다.

```bash
python3 tools/profile_motor_link.py
```

| 요청 송신 주기 | 실측 송신 주파수 | 왕복 응답 지연 (p95) | MCU $\rightarrow$ 호스트 UART 점유율 | 프레임 · CRC · 타이머 오류 |
| --- | --- | --- | --- | --- |
| 20 Hz | 19.8 Hz | 12.4 ms | 23.8% | 0 |
| 50 Hz | 48.7 Hz | 13.7 ms | 31.6% | 0 |
| 100 Hz | 93.1 Hz | 12.3 ms | 43.1% | 0 |

115200 bps(8N1) 대역폭에서 50 Hz 목표 송신과 20 Hz 상태 수신 조합은 약 30% 수준의 UART 점유율로 프레임 손실 없이 안정적으로 동작합니다.
